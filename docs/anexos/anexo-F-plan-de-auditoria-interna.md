# Anexo F. Plan de auditoría interna particularizado al SCE

**Fuente:** SCE-MC-001 v2.0, sección 39 (Tabla 60). Norma: ISO 19011:2018.

El auditor no desarrolla ni opera el producto. Con un equipo de dos personas, **el auditor interno debe ser alguien externo al equipo**; está pendiente de designar (`docs/gobierno/plan-de-sistema.md`, sección 8). PA-SCE-001, del equipo Aerial Forge, es una auditoría académica independiente de este programa.
