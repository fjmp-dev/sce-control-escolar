# Anexo G. Guion de sesión de usabilidad y cuestionario SUS

**Fuente:** SCE-MC-001 v2.0, sección 26. Método: ISO 9241-210:2019. Se aplica en staging, con datos sintéticos y al menos cinco participantes por rol (Batch 13).

**Rol:** alumno · profesor · control escolar · caja
**Participante (código, sin nombre):** `<P-01>` · **Fecha:** `<...>` · **Observador:** `<...>` · **Etiqueta:** `<vX.Y.Z>`
**Consentimiento de grabación de pantalla:** sí · no

## 1. Tareas por rol

| Rol | Tareas |
|---|---|
| Alumno | Iniciar sesión; encontrar inscripción, pagos, horario, calificaciones y trámites; armar una carga; interpretar un rechazo por adeudo, por requisito y por choque; pagar; solicitar y descargar una constancia |
| Profesor | Consultar sus grupos; capturar un parcial; corregir una captura |
| Control escolar | Buscar un expediente; atender una solicitud; emitir una constancia; rechazar una solicitud con motivo. Hacerlo después de una inducción breve |
| Caja | Generar cargos del periodo; registrar una beca; conciliar pagos del día. Hacerlo después de una inducción breve |

## 3. Cuestionario SUS

Marcar del 1 (totalmente en desacuerdo) al 5 (totalmente de acuerdo).

| # | Afirmación | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | Creo que me gustaría usar este sistema con frecuencia | | | | | |
| 2 | Encontré el sistema innecesariamente complejo | | | | | |
| 3 | Pensé que el sistema era fácil de usar | | | | | |
| 4 | Creo que necesitaría ayuda de una persona técnica para poder usarlo | | | | | |
| 5 | Encontré que las funciones del sistema estaban bien integradas | | | | | |
| 6 | Pensé que había demasiada inconsistencia en el sistema | | | | | |
| 7 | Imagino que la mayoría de las personas aprendería a usarlo muy rápido | | | | | |
| 8 | Encontré el sistema muy difícil de usar | | | | | |
| 9 | Me sentí muy seguro usando el sistema | | | | | |
| 10 | Necesité aprender muchas cosas antes de poder usar el sistema | | | | | |

**Cálculo:** en los reactivos impares, puntaje menos 1. En los pares, 5 menos el puntaje. Se suman y se multiplica por 2.5. **Meta: mayor o igual a 70 puntos.**

Los hallazgos entran al backlog con su clasificación.
